- **Datos:** MySQL, PostgreSQL, MongoDB, SQLite
- **Front:** React, TypeScript, MUI, Tailwind CSS

## Cómo está hecho

HTML, CSS y JavaScript sin frameworks ni build. Los textos en español están en `index.html`; las listas y la traducción al inglés, en `assets/js/content.js`. Se publica en GitHub Pages desde `main`.

Para verlo localmente, servir la carpeta con cualquier servidor estático (los módulos ES no cargan con `file://`):

```bash
npx serve .
```
